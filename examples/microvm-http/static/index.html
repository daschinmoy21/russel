Runtimes

One app, two isolation models — switch with a redeploy.

Container

default

Rootless Podman --rootfs from a Nix store package. Fast cold path; ideal for demos and most services.

  • type = "container"
  • rootless Podman required
  • optional Traefik host route

microVM

KVM

Cloud Hypervisor guest with virtiofs /nix/store, custom microvm kernel, passt publish.

  • type = "microvm"
  • needs KVM; ctrl stays unprivileged
  • see examples/microvm-http

Quick deploy

From the Russel repo after cargo build.

# control plane (container-only)
./target/debug/russel-ctrl

# deploy this example
./target/debug/russel deploy examples/microvm-http
